# Catalog of Product Architecture Framework (PAF) Cards

PAF — Product Architecture Framework, [productframework.ru](https://productframework.ru), author Sergey Tikhomirov, license CC BY-SA 4.0, dates are not given on the pages. Below are all cards in the set, each with its origin label.

Labels: **PAF** — the tool is named on the PAF site, the card was in the original set; **PAF, added** — created based on the PAF description; **not from PAF** — not named in PAF as a tool.

Total: 113 cards: PAF — 54, PAF, added — 37, not from PAF — 22.

PAF's descriptions are fuller for tools that PAF has a page for, and thinner for placeholders (SMART Goals, Storytelling, MVP: the site only has the name). Some added cards rely on third-party primary sources, and their cases are mostly not from e-commerce and fintech (the quality report is kept outside the repository).

Not covered (present in PAF, no separate card): 4 Actions Model (in Strategy Canvas — one line), Feature Scoring (PAF has no formula; the closest are ICE and RICE), Hypothesis Card (the closest is Experiment Card), Hypotheses & Experiments Library (the Miro board is unreadable; by text — the same hypothesis and experiment formulas).

## Selection table

Used by `pdm-brief` to keep only the tools that give an honest result with the data a run has. Modes: `none` (the PM's knowledge and assumptions, no numbers), `web` (public facts), `local` (the PM's files), `manual` (company numbers entered by hand as aggregates). A tool lists every mode in which its result stays honest. Stage is the second word of the tool's folder. Status `draft` is set by the agent from the tool's SKILL.md and card.md and is cleared after review. On 26 October 2026 the maintainer authorised the assistant to clear it on rows it is sure of; it did so after checking each row's modes and input against the first step of that tool's SKILL.md. Three rows whose input comes from the card alone (PAF has no description) stay `draft`. `build/quality_gate.py` checks that every tool has exactly one row with allowed modes.

| Skill | Data modes | Stage | Input needed | Status |
|---|---|---|---|---|
| `abc-analysis` | local, manual | analysis | per-object values for one period from one source, as a table or file, or typed totals | reviewed |
| `adl-matrix` | none, web | analysis | business-unit facts, industry-stage factors and position evidence as judgment, plus public industry facts | reviewed |
| `bcg-matrix` | web, local, manual | analysis | market growth and shares per unit (public or estimated), plus unit revenue and cash flow | reviewed |
| `ge-mckinsey-matrix` | none, web, local, manual | analysis | units to place, factors, weights and 1-to-5 or 0-to-10 ratings per unit as the user's judgment with a stated basis; hard market data is optional | draft |
| `product-lifecycle` | web, local, manual | analysis | one comparable metric by year for every year of the product from one source, plus supporting signs | reviewed |
| `sales-funnel` | local, manual | analysis | customer counts entering each funnel stage and time per stage for one period, plus a baseline | reviewed |

## Gaps

Decisions a product team has to make that no card in this catalog covers, and that have no primary source yet. A card is added only when a primary source exists (the method's author or publisher, or the official page of a standard). Each entry: the decision, what is missing, what was searched.

No open gaps. Closed: Balanced Scorecard (Kaplan and Norton, HBR 1992), Pugh Matrix (Pugh, Total Design, 1991), Risk Register (NIST IR 8286r1, December 2025; ISO 31000 is paid, NIST SP 800-30 and 800-37 do not define the register, HM Treasury Orange Book gives no definition).

## Chains

A chain is the order of tools for one piece of work, given by position. A position can list alternatives: the tools in one position are interchangeable for that position, so the skill picks the one that fits the task. The chains are a plugin proposal built from each tool's purpose, not a PAF scheme.

Rule for `pdm-brief`: take the positions in order. When the tools it needs sit in non-adjacent positions, take every position between them and one tool from each.
