# pdm-skills repository rules

## Project structure

- Every presentation project must be placed in its own subdirectory of the workspace root.
- Subdirectory names are written in snake_case: only lowercase Latin letters, digits and underscores (for example, `q3_sales_review`, `product_roadmap_2026`).
- Project files (sources, images, final `.pptx`/`.pdf`) are not put in the root; they are kept in their project's subdirectory.
- Before starting work on a new presentation, first create a subdirectory for it.

## Building templates and plugin cards

- PPTX/XLSX templates in `skills/` are generated by `build/build_templates.py`. To change a template, edit its spec class and rebuild, rather than editing the file itself (see `build/README.md`).
- Cards are written per `build/card_brief.md`; the catalog of tools is `product_notes.md` in the root.
